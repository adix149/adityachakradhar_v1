# Adityachakradhar Reddy — Cinematic Personal Portfolio & Landing Page 🚀

An ultra-modern, high-performance, atmospheric horizontal-scrolling portfolio and digital showcase for **Adityachakradhar Reddy** (Senior Software Engineer @ Google, ex-Salesforce LMTS, ex-Microsoft Bing, ex-Xilinx/AMD, ex-Intel, ex-Samsung, Executive M.Tech IIT Hyderabad, B.E. Hons BITS Pilani).

Built with zero external frameworks or heavy dependencies — pure, semantic HTML5, modern CSS3 variables & animations with pure Gaussian easing, and vanilla ES6+ JavaScript.

---

## 🌟 Key Features

- **Cinematic Celestial & Mountain Aesthetic**: Twilight horizon, ambient glows, starry canvas with meteors, and scenic silhouette layers inspired by luxury Japanese & architectural portfolio design.
- **Buttery Smooth Gaussian Wheel & Touch Scroll**: Converts vertical wheel/trackpad scrolling into buttery smooth horizontal navigation using custom Gaussian acceleration/deceleration S-curves (`cubic-bezier(0.65, 0, 0.35, 1)`) with zero jitter or stutter.
- **Constant Top Navigation Bar**: Stays fixed and synchronized across all 8 slides (`Home`, `About`, `Experience`, `Education`, `Thinking`, `Beyond Code`, `Thoughts`, `Contact`).
- **In-Place Experience Card (Visible by Default)**: Slide 2 features an interactive timeline pathway with an in-place details card showing Google by default. Users can click any company node or quick-selector chip (Ariba, Samsung, Intel, Xilinx, Microsoft, Salesforce, Google) to update the card content smoothly without popups or modals.
- **Dedicated Academic Credentials Screen**: Slide 3 highlights dual prestigious engineering credentials with bespoke insignia crests and coursework tags for:
  - **IIT Hyderabad**: Executive M.Tech in Data Science (2017–2019)
  - **BITS Pilani**: B.E. (Hons) in Electrical & Electronics (2008–2012)
- **Interactive Modals & Deep Dives**: Rich modals for articles, current focuses, and contact dialogs with one-click copy utilities.

## 🚀 Quick Start & How to Run

Because the project uses standard web technologies, **no build step, bundler, or `npm install` is required**.

### Option 1: Open Directly in Your Browser
```bash
open /Users/adityachakradharreddyvari/Documents/Work/MyWebsite1/index.html
```

### Option 2: Run with Python HTTP Server
```bash
cd /Users/adityachakradharreddyvari/Documents/Work/MyWebsite1
python3 -m http.server 8080
```
Then visit: [http://localhost:8080](http://localhost:8080)
